METADATA / DOCUMENTATION ONLY
- package.json — version and description updated to 2.6.8. No dependency changes.

- CHANGED-FILES-v2.6.8.txt — this file.

- public/ website assets and legacy-reference/
- Tier points, tier values, leaderboard calculations and ranking order.

MOBILE DEPLOY
If your GitHub repository is already on v2.6.7, replace only api_server.js to apply the functional changes. Replacing package.json and README.md is optional. Keep Railway environment variables and the existing persistent volume.

AFTER DEPLOY
1. Run /waitlists clear with confirm=true once to delete old queue embed messages from all 66 regional waitlist channels.
2. Run /start queue, choose a gamemode and a region to manually publish that queue's live panel.
3. /wipeall is server-owner only and requires the exact phrase: WIPE ALL ECLIPSETIERS DATA. It creates a backup before wiping.
