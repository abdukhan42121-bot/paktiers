ECLIPSETIERS v2.6.8.2 — MOBILE DEPLOYMENT

This is an API-server-only patch.

1. Download and extract this ZIP.
2. Open your GitHub repository in your mobile browser.
3. Open the existing root-level api_server.js.
4. Replace its contents with the api_server.js from this ZIP.
5. Commit the change and wait for Railway to redeploy.
6. Open Railway Deploy Logs and look for:
   [SLASH SYNC] ✅ Published ... guild commands

Why this fixes it:
Discord rejected the registration request because /waitlists clear declared optional `region` before required `confirm`. Discord requires required subcommand options to be listed first. The options are now declared as `confirm` then `region`.

The command still has the same options and behavior: confirm:true is required; region is optional. No queue data is changed by this patch.

Only api_server.js needs replacing. Do not change railway-gateway.js, package.json, or your Railway volume/environment variables for this fix.
